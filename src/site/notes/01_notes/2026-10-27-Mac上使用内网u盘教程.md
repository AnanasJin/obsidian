# 核心思路
使用utm虚拟化一个x86的win8.1用来打开u盘，再用chfs来对u盘内的文件进行上传和下载

# 准备工作
## 安装utm
直接官网安装
https://getutm.app/
或者使用brew安装utm
```
brew install --cask utm
```
## utm中安装win8.1 x86
1. 下载iso镜像 https://dn720208.ca.archive.org/0/items/win-8.1-english-x-64_20211019/Win8.1_English_x32.iso
2. 使用utm安装win8.1 x86
   2.1. 点+号创建
   2.2 一定要选Emulate![Screenshot 2026-10-27 at 17.18.23.png](/img/user/Screenshot%202026-10-27%20at%2017.18.23.png)
   2.3 选windows
   2.4 选intel ICH9 based PC，其他默认
   2.5 取消勾选install win10，添加win8.1 iso
   ![Pasted image 20261027172204.png](/img/user/Pasted%20image%2020261027172204.png)
   2.6 接下来全默认，一路继续即可创建windows虚拟机。
## 配置win8.1系统
1. 打开虚拟机后就会进入windows系统的安装流程，一路默认即可。激活码可以填  334NH-RXG76-64THK-C7CKG-D3VPT
2. 安装完成后使用ie浏览器下载 http://iscute.cn/tar/chfs/3.1/chfs-windows-x86-3.1.zip 解压后将可运行程序放到桌面。如下图所示：

![Pasted image 20261027170341.png](/img/user/Pasted%20image%2020261027170341.png)

这里选Port
![Pasted image 20261027170416.png](/img/user/Pasted%20image%2020261027170416.png)

# 使用内网u盘
1. 将u盘插上mac后，右上角u盘图标选择你的u盘，点击connect。
![Pasted image 20261027165105.png](/img/user/Pasted%20image%2020261027165105.png)

2. 进入u盘，运行里面的程序，会出现这个界面，乱码不用管，直接在中间输入密码，然后按回车。
![Pasted image 20261027165234.png](/img/user/Pasted%20image%2020261027165234.png)
3. 就会出现带文件的交换区，进入交换区后，将桌面的chfs文件复制到u盘中，然后双击运行即可。
![Pasted image 20261027165345.png](/img/user/Pasted%20image%2020261027165345.png)
4. 最后在你的mac的Safari或者Chrome或者任意浏览器中打开网址 http://192.168.64.2  就能进入到文件传输的网页，至此就大功告成了。
![Pasted image 20261027165449.png](/img/user/Pasted%20image%2020261027165449.png)
